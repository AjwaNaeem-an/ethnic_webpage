# Ethnic – Clothing Store Website

A simple multi-page clothing store website with Eastern and Western wear pages, a login form, dark mode and a product total calculator. It was made as a university web development assignment to practice building a website. Built with HTML, CSS and JavaScript.

## 🚀 How to Run the Project

You can view the live project directly here: [https://ajwanaeem-an.github.io/ethnic_webpage/webpage.html](https://ajwanaeem-an.github.io/ethnic_webpage/webpage.html)

Alternatively, to run it locally:
1. Clone or download this repository.
2. Open the project folder and double-click the `webpage.html` file.
3. The website will open automatically in your default web browser.

Note: For the best experience, use a modern browser like Google Chrome or Mozilla Firefox.
